# Nerosa Elite Business Suite

نظام عربي متكامل لإدارة المبيعات والمشتريات والمخزون والعملاء والأقساط والموظفين والحسابات. يعمل من الهاتف والكمبيوتر، ومجهز للنشر على GitHub Pages مع Supabase.

## المميزات الموجودة

- كاشير سريع للمفرد والجملة والآجل والقسط.
- ماسح باركود يدعم Safari ويتجاهل QR الخاطئ.
- منتجات ومخزون وتنبيهات حد الطلب وسجل مشتريات.
- طباعة باركود فوري بعدد النسخ المطلوب.
- دعم باركود الميزان والمنتجات الموزونة.
- عملاء وموردون وكشف حساب وأرصدة.
- أقساط ومواعيد استحقاق ومتأخرون وتسجيل الدفعات.
- موظفون وحضور وانصراف ورواتب وخصومات ومكافآت.
- مصاريف وسند قبض وصرف وسماح وتصريف.
- تقارير يومية تلقائية للمبيعات والمصاريف والديون.
- مستخدمون مستقلون بكلمات سر وصلاحيات مختلفة.
- إعدادات الشركة والفاتورة وحجم 80mm أو A4.
- الدينار والدولار وسعر صرف قابل للتعديل.
- نسخة احتياطية JSON وخاصية تصفير محمية.
- تصميم عربي RTL متجاوب مع الهاتف والكمبيوتر.

## تجربة البرنامج محلياً

```bash
npm install
npm run dev
```

إذا لم تضف مفاتيح Supabase، يفتح البرنامج في **الوضع التجريبي** وتُحفظ بيانات التجربة على الجهاز فقط.

## ربط Supabase

1. افتح مشروع Supabase.
2. افتح **SQL Editor** وشغّل الملف [`supabase/schema.sql`](supabase/schema.sql) كاملاً.
3. انشر وظيفة إدارة المستخدمين:

```bash
npx supabase login
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase functions deploy pos-admin-users
```

4. انسخ `.env.example` إلى `.env.local` وضع رابط المشروع والمفتاح القابل للنشر:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_YOUR_KEY
```

لا تضع `service_role` أو أي مفتاح سري في ملفات الموقع أو GitHub. وظيفة Supabase تحفظه داخل الخادم فقط.

## النشر على GitHub Pages

الشرح الكامل موجود في [DEPLOY_AR.md](DEPLOY_AR.md). بعد إضافة مفاتيح Supabase إلى GitHub Secrets، سير النشر الجاهز في `.github/workflows/deploy-pages.yml` يبني الموقع وينشره تلقائياً، من دون الاعتماد على ChatGPT أو استضافته.

## أوامر مهمة

```bash
npm run typecheck  # فحص TypeScript
npm run build      # بناء نسخة GitHub Pages
npm run preview    # معاينة النسخة المبنية
```

## ملاحظة الميزان

البرنامج يقرأ باركود الوزن الذي يطبعه الميزان ويكوّن نفس الصيغة للطباعة. الاتصال المباشر بسلك الميزان يعتمد على نوع الجهاز والمتصفح، لذلك الإعداد الافتراضي المضمون هو العمل عبر باركود الميزان.
